# MediConnect DVT Streamlit starter

University educational demonstration only. No real patient data.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Deploy

Upload `app.py` and `requirements.txt` to a GitHub repository, then deploy through Streamlit Community Cloud. Review clinical content and safety rules before evaluation. This app is not suitable for patient care.
